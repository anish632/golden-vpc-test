# Volunteer Pathways Coalition guide

`index.html` is the main page. It has no build step or outside code files.

## Try it on your computer

Open `index.html` in a browser. Or run this command in this folder:

```sh
python3 -m http.server 8000
```

Then open <http://localhost:8000>.

Try all 51 states, Medicaid, SNAP, both programs, the “I’m not sure” path, the nonprofit view, share links, and the hours log. The sample form is `verification-form.html`; the blank log is `volunteer-hours-log-template.csv`.

## Publish with GitHub Pages

Set Pages to deploy from the `main` branch and the root folder. `index.html` is the home page. Keep the form and CSV files in the same folder so their links work.

The state rules can change. Before sharing this guide as advice, check each state entry against that state’s official sources and add a review date.
